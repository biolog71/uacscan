0 THIRD-PARTY DEPS
STDLIB + RAW SYSCALLS
Package architecture / single-binary forensic collector

uacscan

A compile-then-single-pass reimplementation of UAC's offline artifact collection, run against a mounted forensic image.

UAC's shell implementation runs one find(1) per artifact entry — roughly 490 offline entries, twenty of which start at / — so the same inodes get visited dozens of times. uacscan instead compiles every artifact definition into an in-memory predicate (rules.Rule), walks the tree exactly once, and evaluates all rules against a single statx/lstat result per file.

Two invariants shape nearly every package boundary. One stat per file, not one per rule — a single-entry fsref.Cache primed by the walker, which every collector reads from. And one open per file, shared but never as a raw descriptor — content.Broker hands out a revocable ReadAt-only view. Four UAC collectors are in scope (file, find, stat, hash) plus one synthesised kind (list) for a natively-reimplemented two-phase HISTFILE artifact. The 661 command entries, which execute on a live system, are deliberately out of scope.

03 Execution pipeline

Sixteen stages, all inside cmd/uacscan.run() unless noted. Teal badges mark the three stages that define the architecture: the single walk, per-file evaluation, and the single open. Amber marks stages with a fatal exit path.

00
Flag parsing and early exits cmd/uacscan.main

argv becomes flags: -m mount (default /), -o destination (required), -output-base-name, -a artifacts dir override, -extract, -version, -include (default *), -exclude, -start-date-days, -end-date-days, -exclude-path (default /proc,/sys,/dev,/run), -cross-device, -buffer-limit (default 4 MiB), -c conf, -s target OS, -v. -version prints uacdata.Version() and exits; -extract writes the embedded corpus to disk and exits; a missing -o exits 2.

01
Mount validation cmd/uacscan

Trailing / is trimmed, then os.Stat must report a directory.

02
Definition and configuration loading cmd/uacscan.loadDefinitionsuacdataconfig

By default uacdata.Artifacts() returns an fs.FS rooted at artifacts/ and config.LoadFS(full, "config/uac.conf") supplies the conf. With -a dir it becomes os.DirFS(artDir) plus config.Load(<artDir>/../config/uac.conf) — both switch together, so definitions and config can never come from different places.

03
Artifact parsing internal/artifact

LoadFS walks every *.yaml. Per-file parse errors are warnings, not fatal — one malformed artifact cannot kill the collection. Zero docs parsed is fatal.

04
Target-OS resolution internal/targetosfsref

Explicit -s wins; otherwise mount / uses Host(), else Detect(mount) looks for marker files (etc/os-release, System/Library/CoreServices/SystemVersion.plist, bin/freebsd-version, etc/release) through containment-checked existence tests. More specific systems win — netscaler over freebsd, esxi over linux. An inconclusive result yields Unknown, which disables the filter rather than dropping everything.

05
Output directory creation internal/outdir

Hostname(mount) reads the hostname from the image, falling back to the host only when collecting from /. Name(...) produces uacscan-<hostname>-<os>-<timestamp> and Create os.Mkdirs it, appending -2, -3… on collision. There is no locking — Mkdir failing on an existing directory is the mutual exclusion.

06
Environment assembly cmd/uacscanmountspasswd

mounts.Load().Under(mount) and passwd.Load(mount) build the rules.Env: mount point, now, OS, date range, mtime/atime/ctime switches, hash algorithms, mount table, user homes, shell homes, exclude-name pattern, max depth, output dir. UIDs and GIDs are set independently — a passwd file without a group file must not mark everything no_group.

07
Artifact selection and rule compilation internal/rulescmd/uacscan

-include/-exclude compile to globs matched against Doc.Source (exclude wins). For each surviving entry rules.Compile runs: unsupported OS is skipped; collector: command compiles only if it matches a recognised HISTFILE-extraction shape (becoming KindList), everything else skipped; non-offline collectors skipped; is_file_list becomes the consumer half (FromList=true, ListKey) matching nothing directly. Otherwise path values expand into anchors — %user_home% fans one entry into one anchor per home, exclude_nologin_users narrows to ShellUserHomes — patterns become globs, exclude_file_system resolves through the mount table into concrete prune paths, and file type, permissions, size bounds and max depth attach. %user_home% with no homes is skipped, not an error. Compile errors warn and drop. Zero rules is fatal.

08
Output store, cache, broker, collector context spoolfsrefcontentcollector

spool.NewStore(outDir) claims the directory with an O_CREAT|O_EXCL .uacscan-collection marker (the dir must be absent or empty). fsref.NewCache(mount) is the single-entry memo. content.NewBroker() takes the buffer limit and routes read failures into ctx.RecordError. collector.New(rule, ctx) yields one of statCollector, findCollector, hashCollector, fileCollector or listCollector per rule.

09
Prune-set assembly cmd/uacscan

-exclude-path, conf.ExcludePathPattern and mountTable.PointsForTypes(conf.ExcludeFileSystem) combine into both p and p/* globs per entry, deduped and sorted. SkipReal holds the canonicalised (abs + EvalSymlinks) outDir and dest — pruned by resolved path, not glob, because the operator's path may be relative or contain glob metacharacters.

10
The single walk internal/walk.Walker.Walk

Resolve the root, record rootDev, visit it. An explicit LIFO stack of frame{real, rel, depth} drives traversal — no recursion. Each directory is read with os.ReadDir (name-sorted, so output is reproducible); failures are reported and the walk continues. Per entry: globally excluded or SkipReal skips; then fsref.Resolve; unless -cross-device, a differing Dev skips; then visit; then push the frame if it is a descendable directory, else count it skipped. Symlinks are never descended. visit(ref) is the heart: files++, Cache.Set(ref), Broker.Reset(), InspectFile for every collector in order, then Broker.Run(ref). Descent requires Set.MayContainMatches(rel) and that not every collector's ShouldSkipDir agrees.

11
Per-file rule evaluation and metadata output collectorrulesfsref

Each InspectFile calls Cache.Get(path) — a perfect hit rate, since the walker just primed it — then rule.Match(f, env): exclusions, anchor scope and depth, path/name globs, -type, -perm, size bounds, no_user/no_group against the image's passwd DB, and the -mtime/-ctime/-atime range (-N within, +N older, OR'ed; atime off by default). statCollector writes a mactime bodyfile line immediately. findCollector writes the path — or, for the two find+command artifacts, getcap via lgetxattr(security.capability) plus fileattr.Capabilities(), and lsattr via Immutable() from statx, calling fileattr.GetFlags() only for immutable files. hash, file and list collectors read nothing here — they register through ctx.Broker.Want(ruleID, fn). fileCollector dedupes hardlinks by (Dev, Ino) when Nlink > 1.

12
Content service — the single open internal/content.Broker.Run

Returns immediately if nothing registered. Non-regular files hand every consumer a recorded "not a regular file" error — this is what keeps device nodes and FIFOs from ever being opened. Otherwise syscall.Open(real, O_RDONLY|O_NOFOLLOW|O_NONBLOCK|O_CLOEXEC). Files at or under BufferLimit are read whole into one reusable buffer (bufferView); larger ones get an fdView. Consumers run in registration order; IsFatal(err) aborts the scan, anything else is recorded and the run continues. The view is revoked and the fd closed on return, so later use yields ErrExpired. Consumers are hashCollector.digest (md5/sha1 by default), fileCollector.copy, and listCollector.harvest.

13
Second phase — two-phase artifacts walkcollector.Finisher

After traversal every Finisher gets Finish(). Only fileCollector with FromList does work: for each path in ctx.List(rule.ListKey) — populated in stage 12 by listCollector via ctx.AddToList — it calls fsref.ResolveBeneath(mount, p), not another traversal, then Broker.Want plus Broker.Run(f) per file. Unresolvable history files are recorded as evidence about configuration, not ignored.

14
Flush walk.flushcollector.Flusher

Every Flusher flushes its buffered spool.Writer(s).

15
Store close and reporting spool.Storecmd/uacscan

store.Close() flushes every writer and removes files that stayed empty. The report prints output dir, host, definitions source (embedded UAC version and commit, or the checkout path), target OS and the reason for it, mount count, mount point, rule count, files visited, dirs and skipped dirs, walk errors, recorded file errors (pointing at uacscan/errors.txt), elapsed time and µs/file — then store.Manifest(), one line per output file with Rel, line count and byte count.

Result retrieval is not part of the CLI run. Collector.ScanResults() returns an iter.Seq2[Result, error] backed by spool.Lines(path), streaming the spool file back off disk. Nothing is ever materialised as a slice.

06 Cross-cutting concerns

Five concerns that belong to no single package but constrain all of them.

Concurrency model
No intra-scan parallelism. Inter-scan safety by construction.

One goroutine performs the whole walk — no worker pool, no channel fan-out. What the code guarantees is inter-scan safety: concurrent_test.go runs four walkers simultaneously over different images (each with its own cache, broker, context and store) and asserts byte-identical results against a sequential baseline plus non-overlapping output dirs. Another test hammers uacdata.Artifacts() from 16 goroutines against the sync.Once-guarded memFS.

Defensive locking exists anyway — Context carries listMu, errMu, errCount, errOnce/warnOnce; spool.Writer and spool.Store each have a mu. The only package-level mutable state is fsref.openat2Unavailable (an atomic.Bool) and uacdata's sync.Once corpus. Cross-process safety is by construction, not by locking: every run gets a fresh directory plus the O_EXCL marker.

The README documents the concrete failure this replaced — two runs sharing an output dir spliced records from different images into one bodyfile: 19 malformed lines out of 21,912, a correct total line count, and no error reported.

Error philosophy
Two classes, enforced by the type system

content.FatalError splits every failure in two. A partial acquisition that exits zero and looks complete is the worst possible outcome for a forensic tool, and the split exists to make that impossible.

Evidence failure

Unreadable file, bad sector, permission denied, vanished file, unresolvable HISTFILE — ctx.RecordError(path, stage, err) writes to the errors spool, increments a counter, the walk continues and InspectFile returns nil.

Output failure

Spool unwritable, disk full, destination unwritable — wrapped with content.Fatal(...), detected by IsFatal, and the run aborts.

collectors.go::copyTagging hand-rolls the copy loop rather than using io.Copy, precisely because io.Copy returns one undifferentiated error and the errno cannot distinguish a failing destination from an unreadable source — both give EIO/EACCES/EPERM on NFS/FUSE, which had let truncated copies be misfiled as evidence problems.

Hostile-image handling
Path-safety mechanisms

Two inputs are image-controlled — the HISTFILE string from a file's contents, and the copy destination derived from it. Both are contained:

  • CleanImagePath — path.Clean semantics where / means the image root, so a leading .. is absorbed rather than climbing out.
  • ResolveBeneath(root, rel) — cleaning alone is insufficient because the kernel follows symlinks in intermediate components; an image whose /logs points at / turns <mount>/logs/etc/shadow into the examiner's own file.
  • DestinationUnder(dir, rel) — the same check on the write side, since filepath.Join cleans and an escaping path would do so silently.
  • CreateNoFollow and O_NOFOLLOW in spool.Store.Open — a planted symlink cannot redirect evidence out of the collection.
  • OpenBeneath and ReadBeneath — O_NOFOLLOW|O_NONBLOCK, must be regular, size-capped, for every metadata read: hostname, passwd, group, OS markers. Blocks both a symlink to the examiner's filesystem and a FIFO that never opens.
  • targetos.Detect checks markers with containment so a planted symlink cannot steer artifact selection.

No descriptor is ever held in FileRef. The open happens last, only after a rule matched, and only for regular files — which is what stops device nodes in the image's /dev from reaching the examiner's hardware. Documented residual gap: the lstat-based ancestor check is theoretically racy against something mutating the image mid-scan (openat2 closes it on recent Linux only); a forensic image is expected to be static and mounted read-only.

Embedded data and codegen
Two separate archives, deliberately

(1) internal/uacdata/uac.tar.gz — artifacts/, config/, profiles/ and VERSION (428 files, 319 KiB of YAML compressing to 49 KiB), go:embed'd and unpacked into an in-memory memFS (fs.FS plus ReadFileFS and ReadDirFS, with synthesised parent dirs) behind a sync.Once. It never touches disk; the shipped binary is about 3.7 MB.

(2) test/uacfull/uac-full.tar.gz — the entire UAC shell implementation including bin/ (8.6 MB). Nothing outside the harness imports it, so it never reaches the executable, and it does unpack to a temp dir with the exec bit preserved, because you cannot exec a shell script from an in-memory FS.

gen/main.go carves the small archive out of the big one rather than re-packing, so the two can never disagree about which UAC they represent. When packing from a checkout it uses git ls-files rather than a directory walk — a walk picks up editor dirs and destroys reproducibility. Output is deterministic: sorted entries, zeroed timestamps and ownership. Guard tests: TestEmbeddedMatchesCheckout and TestArtifactsAgreeBetweenTheTwoEmbeddedCopies.

Notable divergences
Where uacscan differs from UAC
  • Pruning semantics. In UAC each artifact's exclude_path_pattern prunes its own find; here the walk is shared, so a directory is skipped only when the rule Set cannot reach it and every collector's ShouldSkipDir agrees — same results, different cost.
  • Set.MayContainMatches short-circuits to true whenever any rule has a literal prefix of /. With bodyfile or hash_executables enabled, subtree skipping is pointless and is not attempted.
  • Two intended divergences, which the harness reports as EXPECTED and fails on anything else: no_user/no_group answered from the image's passwd and group (and declined entirely when the image has none); and the HISTFILE lookup reading the image's rc files, where UAC's command collector ignores the mount point and greps the examiner's home directories.
  • Config surprises found by the differential harness: hash_algorithm defaults to md5 plus sha1 (emitting sha256 would silently diverge) and enable_find_atime defaults to false.
